# Happy Dog!

A web app that helps a dog owner find the best dog walker for their dog.

Codesters JavaScript team practice, week 4.

## How to run it

Open a terminal in this folder and start a small server:

```
python -m http.server 8000
```

Then open http://localhost:8000 in your browser and allow location when it asks.

Opening `index.html` straight from the file manager also works, but then the
browser blocks the location, so your own marker will not show up on the map.
